## Références externes

- [Game Programming Patterns (livre gratuit en ligne)](https://gameprogrammingpatterns.com/) — vocabulaire commun avec la lane dev.
- [« Juice it or lose it » — Jonasson & Purho (talk)](https://www.youtube.com/watch?v=Fy0aCDmgnxg) — game feel : la référence sur le juice.
- [The Art of Game Design — Jesse Schell (Book of Lenses)](https://www.schellgames.com/art-of-game-design/) — grille de « lentilles » pour interroger un design.
- [MDA Framework (Hunicke, LeBlanc, Zubek — PDF)](https://users.cs.northwestern.edu/~hunicke/MDA.pdf) — Mécaniques/Dynamiques/Esthétiques, séparer intention et système.
- [The Door Problem — Liz England](https://www.lizengland.com/blog/2014/04/the-door-problem/) — cadrer le périmètre réel d'une mécanique.
- [Prohibition (1987) — MobyGames](https://www.mobygames.com/game/prohibition/) — la source : shooting-gallery, tension crosshair, pop-ups fenêtre.

## MCP / Skills à utiliser

- `bmad-brainstorming` — idéation mécanique. · `bmad-advanced-elicitation` — pressuriser un design.
- `bmad-create-ux-design` — specs de contrôle/interaction. · `bmad-domain-research` — recherche genre/référence.
- `verify` — playtester le build contre les valeurs de la spec.
- (`lead-game-designer`) `bmad-review-adversarial-general`, `bmad-check-implementation-readiness`, `bmad-correct-course`, `bmad-retrospective`.
