Window-align
harness

Les façades IA n'ont pas de grille propre : une grille fixe fait déborder les flics de leur fenêtre, en pose sur le mur nu, et laisse de vraies fenêtres allumées sans personne devant. Ce harness détecte les vraies fenêtres depuis l'art, puis pilote le rendu réel en boucle jusqu'à placer un flic non-débordant par fenêtre.

4types de défaut
≤12itérations
88%remplissage cible
0défaut = succès

Entrées / sortie

Lit public/assets/levels/<id>/facade.png · la bande de jeu windowGrid.top/bottom et le tuning par niveau dans levelArt.json.
Écrit windowZones.generated.json — uniquement la clé du niveau ciblé (belliard / stalingrad / vitry) ; les autres restent octet pour octet identiques. Preuve : overlays .dbg-<id>-align-*.jpg (gitignorés).

La boucle detect-and-correct

détecter · piloter · mesurer · corriger — jusqu'à 0 défaut

1
Détecter les vraies fenêtres de la façade. Étages : belliard = tiers égaux (préserve son résultat livré) ; autres niveaux = détection run-based par étage (robuste à tout nombre d'étages). Les fenêtres sombres/ambiguës ne sont jamais inventées.
2
Piloter le rendu prod live headless (SwiftShader, un flic statique figé par slot) : pousser les zones candidates via window.__MUF_ZONES__ + __MUF_APPLY_ZONES__().
3
Lire chaque boîte de sprite rendue via __MUF_SLOT_RECTS__(). Le mapping hauteur → (taille, y) est calibré sur le premier rendu.
4
Placer un flic non-débordant par fenêtre : régler zone.h (sprite ≈ 88 % de la hauteur d'ouverture) et zone.y, appariement 1:1 zones ↔ ouvertures.
5
Mesurer et corriger en boucle (max 12 itérations) jusqu'à 0 défaut ; overlay de preuve à chaque tour. N'écrit que si convergé.

Les quatre défauts

OVERFLOW — sprite ⊄ ouverture COUNT — nb zones ≠ nb fenêtres EMPTY — fenêtre sans zone WALL — zone sur mur nu
Gate CI--check · qa-lead · Inès 🧪

--check = mesure seule : applique les zones committées, lit les rects rendus, rapporte les défauts, n'écrit rien, exit non-zéro sur tout défaut. --fix (défaut) détecte, corrige, écrit. Le JSON est bundlé au build → rebuild avant un check.

yarn align · yarn align:check · yarn align:belliard[:check]

Data-driven vs grille fixe

belliard21 → 17 slots (5/5/7) · ~3 étages
stalingrad21 → 12 slots (3/5/4) · ~3 étages
vitry20 → 36 slots · ~8 étages HLM denses

Le nombre d'étages n'est jamais présumé · tolérance containment τ = 0.01 · 3 hooks window.__MUF_* dev-only, inertes en production.
