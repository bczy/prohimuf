Level-art
harness

Les niveaux sont data-driven : ciel / façade / rue sont de grandes images générées par IA, compositées en couches parallax. Un manifeste unique décrit tout, et une render farm CI génère l'art, build le jeu, le screenshote et recommite le tout — parce que l'egress réseau est bloqué dans le bac à sable local.

La source unique

tout lit le même fichier

src/game/levels/levelArt.json

style · sizes { sky · facade · street } · levels[] : id · name · label · parallax · prompts

Lu à la fois par l'app (rendu) et par scripts/gen-level-art.mjs (génération). Ajouter un niveau = une entrée ici (+ la map gameplay qui porte les slots d'ennemis). Les prompts sont écrits par concept-artist Maud ✍️, gatés par lead-art Nico 🎯.

Les trois couches

facteur parallax k : place la couche à camera.x · k

k → 1 · dérive la plus lentesky — le ciel lointain, quasi épinglé à la vue
k = 0 · world-lockedfacade — la façade, verrouillée au monde (les fenêtres = slots de flics)
k ≈ 0.04street — la rue au premier plan

Générer l'art

En local (souvent à vide) node scripts/gen-level-art.mjs (manquants) · --force (tout). Images tirées de pollinations.ai (FLUX) → public/assets/levels/<id>/{sky,facade,street}.png. L'egress est généralement bloqué en sandbox — la génération se fait donc en CI.
Dev sans art yarn dev tourne sans aucune image : LevelBackdrop retombe sur des aplats de couleur quand les PNG manquent. Pull la branche après un run CI pour récupérer l'art committé.

La render farm

.github/workflows/preview.yml — vrai Chromium avec WebGL, que le sandbox local n'a pas

1
Générer l'art de niveau manquant (IA, pollinations FLUX).
2
yarn build — compile le jeu.
3
Piloter le jeu buildé headless et screenshoter le menu + chaque niveau en 3840×2160, après 15 s d'attente pour que les flics apparaissent.
4
Stitcher une contact sheet screenshots/overview.png.
5
Recommiter public/assets/levels/ + screenshots/ sur la branche.

Déclenchement : push sur la branche, ou Actions → Run workflow → regenerate = true pour rouler des variantes fraîches.

Aligner les fenêtres de flics

Les façades IA n'ont pas de grille propre, donc une grille fixe fait déborder les flics ou les pose sur le mur nu. Deux outils gardent les window zones (windowZones.generated.json) honnêtes :

gen-window-zones.mjs snappe la grille sur la lumière chaude des fenêtres · align-windows.mjs est le harness detect-and-correct (voir l'infographie dédiée), avec --check comme gate CI.
